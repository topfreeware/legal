HEIC Batch Converter Pro — Open-source components

Updated: 2026-10-12 · Applies to HEIC Batch Converter Pro 1.0 for Windows (Microsoft Store)

HEIC Batch Converter Pro decodes HEIC / HEIF photos with the following libraries. Each is licensed under the GNU Lesser General Public License, version 3 (LGPL-3.0; libde265 and libheif: version 3 or later). Each is shipped as a separate file in the app’s installation folder (libde265.dll, libheif.dll, LibHeifSharp.dll) and can be replaced by another build with the same interface. The complete corresponding source code is provided below.

How the libraries are built

  1. Windows x64 with Visual Studio’s “Desktop development with C++” (MSVC), CMake and Ninja; Release configuration, dynamic C runtime (/MD), reproducible builds (/Brepro).
  2. build-native.ps1 clones each library at the tag above, checks the commit, applies the patch to libde265, and runs CMake with the options listed in native-libs.json. You can do the same by hand from the source archives: extract, configure with those CMake options, build.
  3. To use your own build, replace libde265.dll and/or libheif.dll (built from these or later compatible sources) in a copy of the application folder.

HEIC Batch Converter Pro — 开源组件

更新：2026-10-12 · 适用于 Microsoft Store 上的 Windows 版 HEIC Batch Converter Pro 1.0

HEIC Batch Converter Pro 使用下列库解码 HEIC / HEIF 照片。它们都采用 GNU 宽通用公共许可证第 3 版（LGPL-3.0；libde265 与 libheif 为第 3 版或更高版本）。每个库都以独立文件（libde265.dll、libheif.dll、LibHeifSharp.dll）随应用安装，可以替换为接口相同的其它构建。完整的对应源代码见上方下载列表。

  • libde265 1.1.3：改动一行——单个 NAL 单元大小的默认上限由 16 MiB 提高到 256 MiB，使以单个 NAL 单元存储的大照片（如 4800 万像素）可以解码；其它安全上限不变。见补丁文件。
  • libheif 1.23.6：未改动；只启用经由 libde265 的解码（其它编解码器、插件与工具全部关闭，构建选项见 native-libs.json）。
  • LibHeifSharp 3.2.0：未改动（NuGet 包原样使用）。

构建方法：Windows x64 + Visual Studio“使用 C++ 的桌面开发”（MSVC）+ CMake + Ninja，Release、动态 C 运行库（/MD）、可重现构建（/Brepro）。build-native.ps1 按上表的标签克隆源码、核对提交号、给 libde265 打补丁，再用 native-libs.json 中的选项构建；也可以用上面的源码压缩包手工完成。要使用自己的构建，在应用文件夹的副本中替换 libde265.dll 和 / 或 libheif.dll 即可。
